20 ways to elevate the experience

Ranked by impact × effort. "Quick win" tags = implementable in under 2 hours.

Wow Quick Win
Animated count-up on KPI cards
Numbers count from 0 to their real value with a short spring when data loads. Makes revenue and fleet figures feel live and significant — users notice the update instantly instead of a flat swap.
KPICard.tsx + react-native-reanimated (already installed)

Wow Quick Win
Pulsing "Live" indicator in dashboard header
The static gold dot on the Live pill should pulse (scale + opacity loop) using Reanimated withRepeat. One small detail that immediately signals real-time data without any copy change.
DashboardScreen.tsx → liveDot style

High Quick Win
Haptic feedback on every interactive element
tapLight and selectionTick are already defined in lib/haptics and wired in FinanceScreen. The Dashboard quick-action buttons, filter chips, and booking card presses have no haptics — adding them takes 1 line per touch handler and dramatically improves perceived quality on iPhone.
DashboardScreen.tsx, BookingsScreen.tsx — import tapLight
🌊
High Quick Win
Skeleton → content fade transition
The dashboard currently uses display:'none' to swap the skeleton out for real KPI cards — an instant jump. Replacing this with FadeSlideIn (already in ui/) gives a smooth 250ms fade that feels intentional rather than a content pop-in.
DashboardScreen.tsx → kpiGrid section, FadeSlideIn.tsx
💰
Wow
Hero revenue figure counts up on first load
The large 42px revenue number in the hero card is the first thing seen after login. Animating it from 0 to the actual value using withTiming (800ms, ease-out) makes every dashboard open feel like a reveal — especially impactful when the number is large.
DashboardScreen.tsx → heroValue, useDashboardCalculations
🟠
High
Pulse animation on In-Progress booking badges
Active trips should feel alive. A subtle dot-pulse (the badge's status dot scales 1→1.3→1 on a 2s loop) draws the eye to bookings that need attention without changing any layout. Uses withRepeat + withSequence.
RecentBookingsWidget.tsx → StatusBadge, BookingCard.tsx

Wow
Chart line draw animation on mount
Revenue vs Expenses lines currently appear instantly. Animating the SVG path strokeDashoffset from the path length to 0 (750ms, ease-in-out) creates a satisfying draw-in effect. Combined with the area fills fading in at 400ms, the chart feels crafted rather than rendered.
RevenueVsExpensesChart.tsx
📋
Wow
Swipe-to-reveal actions on booking rows
Swipe left on a booking to reveal Edit and Cancel actions (the standard iOS gesture). Swipe right to mark as confirmed. Eliminates the modal tap → edit flow for common actions and gives a distinctly native, high-quality feel that competitors rarely implement.
BookingsScreen.tsx — react-native-gesture-handler Swipeable
🔔
High
Active bookings badge on tab bar icon
Show the count of active (In-Progress + Confirmed) bookings as a badge on the Bookings tab icon. This is the most used screen and a count badge is the first thing power users scan on app open. Wired through React Navigation's tabBarBadge.
App.tsx (tab navigator) → tabBarBadge prop

High Quick Win
Show trip duration in booking rows
Recent Bookings currently shows only start_date. Displaying "14 Jun – 19 Jun (5 nights)" in the date area gives dispatch managers instant context without opening the detail modal. The end_date field is now correctly passed to the widget.
RecentBookingsWidget.tsx → BookingListItem, lib/utils.ts
↕️
Wow
Bottom sheet for quick-action modals
New Booking, Add Expense, and New Safari open as full-page modals. Replacing them with bottom sheets (slide up from bottom, drag to dismiss) matches the native iOS pattern users expect for quick forms, reduces visual interruption, and feels significantly more premium.
NewBookingModal, AddExpenseModal, CreateSafariModal — @gorhom/bottom-sheet
🌙
High
Full dark mode support
userInterfaceStyle is set to 'automatic' but all components use hardcoded light colours. The app appears broken in dark mode on iPhones with system dark mode. Adding a ThemeContext that switches all colour tokens is the single largest perceived quality improvement for end-users.
src/lib/theme.ts + src/constants/colors.ts — useColorScheme hook
🔍
Medium Quick Win
Long-press on KPI cards for detail breakdown
Long-pressing Total Revenue could show a quick popover: MTD vs YTD, top source, vs last month. Same for Fleet Utilization. No new screen needed — a simple Alert or small overlay. Rewards power users who want more detail instantly.
KPICard.tsx → onLongPress prop, DashboardScreen.tsx
🚗
Wow
Vehicle photos in Fleet screen
The Fleet screen shows vehicle cards with text metadata. Adding a hero image (the safari vehicle photo assets are already in assets/safari/) transforms this from a data list to a visual fleet gallery that makes the premium brand tangible. Use ImageBackground with a gradient overlay for the card.
VehicleCard.tsx — assets/safari/jackal-land-cruiser.jpg available
📡
High
Offline / connectivity banner
When the device loses connectivity, data silently stops updating. A non-blocking banner at the top ("No connection — showing last sync") prevents user confusion and tells them why numbers look stale. NetInfo + InAppNotificationBanner (already exists) makes this a small addition.
App.tsx or DashboardScreen.tsx — @react-native-community/netinfo
📈
Medium
Chart tooltip entrance animation
When a month chip is tapped and the detail card appears in RevenueVsExpensesChart, it snaps in instantly. Wrapping it in a scale(0.95→1) + opacity(0→1) animation over 200ms with withSpring makes the interaction feel immediate and tactile rather than a layout jump.
RevenueVsExpensesChart.tsx → detailCard
🧩
Medium Quick Win
Consolidate formatCurrency to a single utility
TopVehiclesChart and ExpenseCategoriesChart each define their own formatCurrency function with slightly different formatting rules, which will eventually drift. Importing from lib/utils.ts everywhere ensures consistency in how K/M abbreviations and currency prefixes render across every screen.
TopVehiclesChart.tsx, ExpenseCategoriesChart.tsx — remove local fn
🏕️
Wow
Safari-themed illustrated empty states
Empty states currently use generic emoji + text. Replacing with on-brand SVG illustrations (a Land Cruiser on a horizon, a compass, binoculars) turns dead ends into moments of delight. One reusable IllustratedEmptyState component, four illustrations, covers the whole app.
src/components/ui/EmptyState.tsx — EmptyState component
✅
High Quick Win
Success feedback after form submissions
New Booking and Add Expense modals close on success with no acknowledgement. A brief success animation (green checkmark + "Booking created" toast via InAppNotificationBanner) confirms the action was saved. Eliminates the user anxiety of "did that actually save?".
NewBookingModal.tsx, AddExpenseModal.tsx, InAppNotificationBanner.tsx
🔗
Medium
Deep links from notifications to bookings
Tapping a push notification about a booking status change should open that specific booking's detail modal directly, not just the Bookings list. Expo Linking + React Navigation's navigate('Bookings', { openBookingId }) routes the user to exactly the right record in one tap.
NotificationsScreen.tsx, App.tsx — Expo Linking config
